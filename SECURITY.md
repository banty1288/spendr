# Security Policy

## Supported Versions

Currently, only the `main` branch of Spendr receives security updates. If you are forking or maintaining your own instance, we recommend staying synced with `main`.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for Spendr, especially because we handle personal financial tracking. If you discover a vulnerability, **do not open a public issue.** 

Instead, please privately report it to the repository maintainers via GitHub's private vulnerability reporting feature, or by contacting the maintainer directly. 

When reporting a vulnerability, please include:
- A detailed description of the vulnerability and its impact.
- Steps to reproduce the issue.
- (Optional) A proposed fix or mitigation.

We will review the report and aim to provide an initial response within 48 hours. If the vulnerability is confirmed, we will issue a patch and a security advisory.
